# First-workflow usability replay

This hermetic replay exercises the README path in a temporary repository:
proposal, explicit approval, one tested task, acceptance, and archive.

```text
python3 examples/first-workflow/run.py
```

The result is one JSON record with the defined persona, timer boundary,
success outcome, elapsed time, and authoritative terminal path. It is an
automated first-time-path proxy, not a human participant study. The bounded
claim and sample interpretation are documented in
[`docs/usability/first-workflow-15-minute.md`](../../docs/usability/first-workflow-15-minute.md).
