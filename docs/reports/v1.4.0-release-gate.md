## Change evidence

This release adds fail-closed reconstruction for registered legacy proposal and
archive formats, including read-only projections, exact digest confirmation,
private staged copies, retryable commit receipts, and explicit restore. It also
adds bounded high-risk proposal discovery, approval-relevant baselines,
authority-split checks, and one-question intake boundaries.

The release matrix now requires one valid run for every Agent/scenario cell.
Both Agents and all 20 scenarios remain covered; the 95% aggregate adherence
threshold, zero-Critical gate, invalid-run classification, and invalid-only
retry policy remain unchanged.

## SemVer and scope review

Versioning policy §2 classifies this release as MINOR because it adds
backward-compatible recovery commands and proposal-intake behavior without
changing existing lifecycle authority, schemas, JSON output, or machine
envelopes.

Engine generation advances to `1.4`; proposal schemas v1/v2, JSON output v1,
discovery/handshake versions, and every machine-envelope version remain
unchanged. Existing valid proposals require no migration. Before starting a
reconstruction, pinning the complete v1.3.0 package is a direct rollback;
after staged recovery begins, v1.4.x must resume or restore its operation
receipt.

The staged release contains no raw Agent transcripts, credentials, absolute
user paths, or unrelated working-tree changes. No file under `eval-runs/` is
staged; raw run artifacts remain ignored.
