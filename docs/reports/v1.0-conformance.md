## Regression disposition

The first full run correctly failed package validation because earlier local
test commands had generated ignored `sdd_core/__pycache__/*.pyc` files inside
the installable package. No source or contract behavior failed. The generated
cache was removed, the package boundary was revalidated, and the entire
18-case suite then passed. The final package contained no generated bytecode.

`PYTHONDONTWRITEBYTECODE=1` remains part of the conformance runner subprocess
environment, and package validation continues to reject any cache or `.pyc`
that exists before a release run. This preserves both clean execution and a
fail-closed package gate.

drills, examples, final version identity, and release notes remain separate
