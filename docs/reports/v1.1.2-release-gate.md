## SemVer and scope review

Versioning policy §2 classifies this release as PATCH. The new command-data
fields are optional presentation data that output-v1 consumers may ignore;
they do not change mutation inputs, authority, error actions, defaults, or
required reader behavior. The Agent optimization consumes those fields while
preserving every existing lifecycle and fail-closed boundary.

Engine generation remains `1.1`; proposal schemas v1/v2, JSON output v1,
discovery/handshake versions, and every machine-envelope version remain
unchanged. The release contains no folded package bootstrap, Schema v3,
locking or lease system, Web UI, external-platform authority, or multi-Agent
orchestration.

The staged release contains no raw Agent transcripts, credentials, absolute
user paths, or unrelated working-tree changes. The only tracked files under
`eval-runs/` are de-identified freeze registries; raw run artifacts remain
ignored.
