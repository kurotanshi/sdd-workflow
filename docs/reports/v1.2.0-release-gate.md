## Change evidence

This release adds an explicit, optional `自審提案` phase and its bounded review
reference. The phase verifies an existing proposal against repository evidence,
may correct concrete draft gaps in place, keeps approved prose read-only, and
never approves or implements. Trigger precedence prevents the `提案` substring
from creating a new proposal during self-review.

The Chinese and English READMEs now document the self-review step, workflow
boundary, and current release. They also add a Contributors image linked to the
repository's native contributor graph. Package and trigger tests pin the new
reference and public guidance.

The release also retains the measured CUT decision for single-status authoring;
that candidate did not enter the Skill runtime.

## SemVer and scope review

Versioning policy §2 classifies this release as MINOR because it adds a
backward-compatible optional Agent phase and explicit trigger without changing
existing lifecycle authority, defaults, schemas, CLI commands, or machine
envelopes.

Engine generation advances to `1.2`; proposal schemas v1/v2, JSON output v1,
discovery/handshake versions, and every machine-envelope version remain
unchanged. Existing proposals require no migration, and pinning the complete
v1.1.3 package remains a direct rollback before using the optional phase.

The staged release contains no raw Agent transcripts, credentials, absolute
user paths, or unrelated working-tree changes. No file under `eval-runs/` is
staged; raw run artifacts remain ignored.
