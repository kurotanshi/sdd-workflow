(文件, 1/1 tasks, anchor-test-first):

- `references/proposal-authoring.md` gains a conditional "Intake, before
  authoring" block: identify assumptions and missing information that could
  materially change the requested behavior, scope, impact, or acceptance
  conditions; a requested implementation approach is not automatically the
  desired outcome; on material ambiguity briefly state the decision-relevant
  gaps and ask exactly one most-critical question before drafting; otherwise
  draft directly, marking safely deferable uncertainty, without a fixed

  documentation-consistency assertions.

  anchor assertions in `tests/test_skill_reduction.py` so the reference

The release ships instruction-text refinement, contributor documentation, and
an anchor test, so it is published rather than left only on the moving
default branch. It is PATCH because the new prose details how to satisfy an
already-stated rule without changing any user obligation, default, authority,
command, schema, or machine behavior.

output v1, and every machine-envelope version. It contains no fast path,
Schema v3, locking or lease system, Web UI, external-platform authority, or
multi-Agent orchestration.

The staged release contains no raw Agent transcripts, secret-bearing eval
artifacts, absolute user paths, or unrelated working-tree changes.
