The release contains no Schema v3, locking or lease system, Web UI,
external-platform authority, or multi-Agent orchestration. Security/trust,
non-goals, migration, rollback, Semantic Versioning, and deprecation documents
were reviewed against the candidate.

The working tree contained pre-existing user edits to README roadmap wording
and `ROADMAP.md`; they were excluded from the release commit and do not affect
the candidate evidence.
