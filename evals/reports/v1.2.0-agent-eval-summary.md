## Candidate evidence

The candidate adds the explicit, optional `自審提案` phase. It reviews an
existing proposal against concrete repository evidence, may correct bounded
draft gaps in place, and keeps approved proposal prose read-only. The phase
never approves or implements. README guidance now documents this phase and
adds an automatically maintained Contributors section.

The proposal schemas, CLI command surface, JSON output, lifecycle transitions,
machine authority, and supported installation contract remain unchanged.
