# v0.9 Skill reduction experiment

Status: **KEEP** the reduced Skill measured 2026-07-23

## Decision

The reduced Skill is retained. Its Agent adherence is equal to the accepted
v0.7 baseline, it has no Critical Violations, the trigger contract still
passes, and the controlled main-prompt proxy is 46.3% smaller.

The end-to-end token diagnostic increased for both Agent hosts. That result is
reported rather than treated as a reduction: the v0.9 matrix ran against a
larger repository snapshot with new protocol, conformance, adapter, example,
and documentation context, so it cannot isolate the Skill's contribution.
Efficiency is diagnostic-only and cannot offset an adherence or safety
failure.
